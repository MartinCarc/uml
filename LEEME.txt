1. SUPABASE
Abrí SQL Editor → New query. Copiá TODO el contenido de supabase/migrations/20261108_fulham_pes13_cards.sql y ejecutalo con Run.
Es una consulta nueva: no reemplaza ni requiere volver a ejecutar las anteriores. Este SQL ya prepara el campo si falta y carga las tarjetas; no necesitás ejecutar otro SQL de tarjetas.

2. GITHUB
Reemplazá js/pages.js y styles.css respetando sus carpetas. Subí también AGENTS.md para guardar las indicaciones y el archivo SQL a supabase/migrations como registro del cambio.
Subir el SQL a GitHub no lo ejecuta en Supabase.

3. VERIFICACIÓN
Esperá el despliegue de Vercel, recargá la web con Ctrl+F5 y abrí Fulham → un jugador → Tarjetas PES 2013.
Ejemplos:
- Alex Iwobi: P05 y P06; S07, S08, S09, S10 y S12.
- Benjamin Lecomte: S26 · GK Long Throw.
- Bernd Leno: sin tarjetas en ambos grupos.

Solo aparecen las tarjetas asignadas en el CSV. Los códigos y nombres se conservan como en el editor. Estilos de juego y habilidades especiales se muestran separados. Cuando una categoría está vacía, indica Sin tarjetas; otros jugadores que todavía no se importaron muestran Tarjetas pendientes de cargar.

Son 25 jugadores: 13 con tarjetas y 12 sin tarjetas, 42 asignaciones en total. La carga utiliza las filas FULHAM y confirma nombre e ID PES con el EDIT correcto y los UUID actuales de la web. No importa jugadores de otros clubes del CSV.

No cambia habilidades numéricas, medias, valores, dorsales, posiciones, formaciones ni estadísticas de partidos. Se mantiene el valor destacado en la cabecera y los indicadores de 2 en 2.

Si algún jugador falta, cambió de nombre/equipo/estado o ya tiene tarjetas diferentes, la consulta se cancela completa. En ese caso, compartí el error para revisarlo; no borres información. Repetir la carga no duplica tarjetas ni sustituye tarjetas diferentes.

Pruebas: carga y repetición en una base aislada con el esquema de UML; conservación de todos los demás campos; cancelación atómica ante conflictos; las 25 fichas comprobadas en navegador y vista a 320/390 px. No se ejecutó la carga en tu Supabase ni se publicó la web desde este entorno.
